BMW M5 G90 2025 - procedural Blender model

Status
------
This is an original, manually generated proportions-based base model.
It is not a source-CAD, scan-derived or photogrammetry model.
It is suitable as a first-pass Blender/GTA asset and preview mesh,
but it requires a second high-detail pass for exact production accuracy.

RAGE:MP/FiveM production requirements
--------------------------------------
The generated universal model is not an in-game GTA vehicle yet.
Production GTA conversion still requires:
- GTA LOD hierarchy
- GTA collision mesh
- Named dummy nodes
- Vehicle flags and handling
- Realistic wheel, door and bonnet pivot transforms
- UV/texture baking
- GTA-compatible YDR/FIVEM resource package
- Platform-specific export workflow
